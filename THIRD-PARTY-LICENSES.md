# Third-Party Components and Licenses

BhashaSetu incorporates open-source machine-learning components.
The respective third-party licenses apply to their corresponding
components and model artifacts.

## Vosk

**Component:** Vosk Hindi small speech recognition model  
**Used for:** Offline Hindi speech recognition  
**License:** Apache License 2.0

Vosk is used as the offline speech-recognition component of
BhashaSetu.

Source:
https://github.com/alphacep/vosk-api

Model information:
https://alphacephei.com/vosk/models

The model's reported benchmark Word Error Rates (WER) are
documented in the README distributed with the model files.

## IndicTrans2

**Component:** IndicTrans2 Indic-Indic Distilled 320M model  
**Model:** `ai4bharat/indictrans2-indic-indic-dist-320M`  
**Used for:** Hindi–Santali machine translation  
**Model checkpoint license:** MIT License

IndicTrans2 is developed by AI4Bharat.

Source:
https://github.com/AI4Bharat/IndicTrans2

The model checkpoint is included in BhashaSetu to support
offline translation.

## BhashaSetu

BhashaSetu's application code and integration work are separate
from the third-party components listed above.

Third-party licenses continue to apply to their respective
components and model artifacts.
