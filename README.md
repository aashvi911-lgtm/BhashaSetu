# BhashaSetu

### Offline Hindi → Santali Learning Assistant for the Classroom

BhashaSetu is an Android application designed to help bridge the language gap between Hindi-speaking teachers and Santali-speaking students.

The application combines offline speech recognition, machine translation, and classroom learning tools into a single mobile workflow.

---

## Problem

In multilingual classrooms, teachers and students may not share the same primary language. This can make classroom communication and learning difficult, particularly when reliable internet connectivity is unavailable.

BhashaSetu focuses on Hindi-speaking teachers working with Santali-speaking students by providing a simple offline-first learning assistant.

---

## Key Features

- Hindi → Santali text translation
- Offline Hindi speech recognition
- Voice-to-translation workflow
- Saved vocabulary and learning Materials
- Printable worksheets
- Printable flashcards
- Santali Ol Chiki script support
- Local/offline model execution
- Curated vocabulary for reliable demonstration outputs
